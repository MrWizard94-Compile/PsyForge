# PsyForge Model Registry

| Model version | Status | Inputs | Output | Approval boundary |
|---|---|---|---|---|
| `1.0` (Descriptive Engagement Baseline) | Local review only | Four approved seven-day behavioral features | Descriptive engagement index, explanation, low confidence | May create a pending recommendation; cannot trigger an action |

Registry changes require a model card, evaluation card, feature/purpose review, source and license record where applicable, deterministic tests, rollback artifact, and named human approval. No unregistered model result may enter the recommendation queue.
