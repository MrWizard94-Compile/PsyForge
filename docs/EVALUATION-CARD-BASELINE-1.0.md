# Evaluation Card: Descriptive Engagement Baseline 1.0

## Evidence available

The current evidence is deterministic synthetic-fixture verification, not a performance evaluation. Automated tests establish strict input validation, consent and tenant enforcement, bounded seven-day features, repeatable output, evidence linkage, low-confidence marking, and review-state controls.

## Metrics intentionally absent

There are no accuracy, recall, calibration, lift, demographic-parity, or causal-impact metrics because this slice has no consented labeled dataset and makes no predictive claim. Reporting those metrics now would be fabricated evidence.

## Gate for future evaluation

Before claiming effectiveness, the project must register a consented and purpose-limited held-out dataset, specify a non-harm outcome, establish leakage controls, define subgroup/privacy analysis, pre-register success and rollback thresholds, and obtain ethics approval. Evaluation must compare the registered model version with a documented baseline and retain reproducible aggregate evidence only.

## Current result

Baseline 1.0 is accepted only as a deterministic descriptive artifact for local human review. It is not accepted for player-level intervention, deployment, revenue optimization, or scientific inference.
