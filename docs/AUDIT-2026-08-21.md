## Verified implementation boundary

- **P0–P4:** consented local telemetry, deterministic feature definitions, an explicitly low-confidence descriptive baseline, and immutable human review remain local, purpose-limited, and non-autonomous.
- **P5:** bounded source content is SHA-256 hashed at the boundary, then discarded; SQLite persists metadata, digest, byte count, rights state, and immutable review/revocation facts only. Private tokens bind actor/tenant/role and forged identity headers are ignored.
- **P6:** the approved kernel is one synthetic, observed, structural relation: `Corpus Concept → Belongs_To → Domain Entity`. Writes require an operator plus an approved, non-revoked P5 `synthetic_test`/`synthetic` source. Nodes/assertions/invalidation rows/audits are immutable, source revocation atomically invalidates active assertions, fixture import/export is bounded and deterministic, and the dashboard inspector is read-only.

The local service is not a hosted platform, telemetry SDK, retained corpus, broad graph, causal-inference engine, embedding/retrieval path, local model runtime, agent runtime, simulation engine, game integration, production writer, multi-user identity system, or compliance certification.
