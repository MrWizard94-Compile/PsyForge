## Orientation findings

- PsyForge's product contract is a local-first behavioral reasoning platform: consented telemetry → validated features → explainable models/simulations → ethics-scored, human-reviewed recommendations.

A bounded loopback Node/SQLite service now implements P0–P4 consented intake, local persistence, deterministic features, a descriptive baseline, and human-only review; it has no SDK, cloud deployment, external provider, agent runtime, or production write.
